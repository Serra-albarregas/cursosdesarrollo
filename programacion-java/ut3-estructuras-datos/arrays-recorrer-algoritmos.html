3. Recorrer arrays y algoritmos básicos

La gran ventaja de los arrays es que podemos recorrerlos con un bucle y aplicar la misma operación a todos sus elementos. En esta página vemos las dos formas de recorrerlos y los algoritmos más habituales: sumar, calcular la media, buscar el máximo, contar, buscar un valor e invertir.

Recorrer un array​

Con for clásico​

Es la forma más flexible. Usamos un contador i que recorre los índices del 0 al length - 1:

int[] alturas = {134, 156, 190, 176, 167};

for (int i = 0; i < alturas.length; i++) {
    System.out.println(alturas[i]);
}

Con for-each​

Cuando solo queremos leer todos los elementos, de principio a fin, existe una forma más corta. En cada vuelta, la variable medida toma el valor de un elemento distinto:

for (int medida : alturas) {
    System.out.println(medida);
}

Se lee como «para cada medida en alturas».

¿Cuál usar?​

for clásicofor-each
Conoces el índice (i)SíNo
Puedes modificar los elementos del arraySí (alturas[i] = ...)No: medida es una copia del valor
Puedes recorrer solo una parte o al revésSíNo, siempre recorre todo
Código más cortoNoSí
El for-each no modifica el array

En este código el array no cambia, porque medida es solo una copia del elemento:

for (int medida : alturas) {
    medida = 0;     // solo cambia la copia
}

Para modificar los elementos hay que usar el for clásico: alturas[i] = 0;.

Rellenar un array​

Con el for clásico podemos pedir los datos al usuario o calcularlos:

// Rellenar con los diez primeros múltiplos de 3
int[] multiplos = new int[10];
for (int i = 0; i < multiplos.length; i++) {
    multiplos[i] = 3 * (i + 1);
}
// Rellenar con valores aleatorios entre 1 y 100
Random generador = new Random();
int[] aleatorios = new int[8];
for (int i = 0; i < aleatorios.length; i++) {
    aleatorios[i] = generador.nextInt(100) + 1;
}

Sumar y calcular la media​

La suma es un ejemplo clásico de acumulador: una variable que va acumulando el resultado.

int[] notas = {7, 5, 9, 4, 8};

int suma = 0;
for (int nota : notas) {
    suma += nota;
}

double media = (double) suma / notas.length;
System.out.println("Suma: " + suma);       // 33
System.out.println("Media: " + media);     // 6.6
División entera

Si dividimos suma / notas.length (dos enteros), Java descarta los decimales y obtendríamos 6. Hay que convertir uno de los operandos a double, como en el ejemplo.

Máximo y mínimo​

La idea es suponer que el primer elemento es el máximo y recorrer el resto: cada vez que aparece uno mayor, nos lo quedamos.

  • Código
  • Demo
int[] numeros = {12, 45, 7, 89, 23, 56};

int maximo = numeros[0];
for (int i = 1; i < numeros.length; i++) {
    if (numeros[i] > maximo) {
        maximo = numeros[i];
    }
}
System.out.println("El máximo es " + maximo);   // 89

¿Por qué empezar en numeros[0] y no en 0?

Si inicializáramos maximo = 0, un array con todos los números negativos daría un resultado incorrecto (0, que ni siquiera está en el array). Partir del primer elemento funciona siempre. El bucle empieza en i = 1 porque el elemento 0 ya lo hemos usado como punto de partida.

Para el mínimo es idéntico, cambiando > por <.

Máximo y su posición​

A veces nos interesa saber dónde está el máximo, no solo cuánto vale. En ese caso guardamos el índice:

int posMaximo = 0;
for (int i = 1; i < numeros.length; i++) {
    if (numeros[i] > numeros[posMaximo]) {
        posMaximo = i;
    }
}
System.out.println("El máximo está en la posición " + posMaximo);   // 3

Contar elementos que cumplen una condición​

Un contador que solo aumenta cuando se cumple la condición:

int[] edades = {15, 22, 17, 30, 18, 12};

int mayoresDeEdad = 0;
for (int edad : edades) {
    if (edad >= 18) {
        mayoresDeEdad++;
    }
}
System.out.println("Hay " + mayoresDeEdad + " mayores de edad");   // 3

Buscar un valor (búsqueda lineal)​

Recorremos el array hasta encontrar el valor o hasta llegar al final. Usamos una bandera: una variable boolean que indica si ya lo hemos encontrado y nos permite parar el bucle.

  • Código
  • Demo
int[] numeros = {12, 45, 7, 89, 23, 56};
int buscado = 89;

boolean encontrado = false;
int posicion = -1;
int i = 0;

while (!encontrado && i < numeros.length) {
    if (numeros[i] == buscado) {
        encontrado = true;
        posicion = i;
    }
    i++;
}

if (encontrado) {
    System.out.println("Encontrado en la posición " + posicion);
} else {
    System.out.println("El valor no está en el array");
}

Convención del -1

Es habitual usar -1 como valor de «no encontrado», porque -1 nunca puede ser un índice válido.

El orden de las condiciones importa

En !encontrado && i < numeros.length, Java evalúa de izquierda a derecha y se detiene en cuanto el resultado ya es seguro. Aquí no genera problemas porque i no se usa como índice dentro de la condición. Pero fíjate en el siguiente apartado: cuando la condición sí usa numeros[i], hay que comprobar primero que i está dentro del array.

Array con zona útil (valor centinela)​

A veces el array es más grande que la cantidad de datos reales, y un valor especial (aquí, el 0) marca dónde termina la parte «útil». Ese valor especial se llama centinela.

int[] array = {2, 4, 8, 12, 16, 18, 20, 10, 9};
array[5] = 0;     // a partir de aquí, la zona útil termina

int i = 0;
while (i < array.length && array[i] != 0) {
    System.out.println(array[i]);
    i++;
}
// Muestra: 2, 4, 8, 12, 16
Índice012345678
Valor2481216020109
Primero el límite, después el elemento

La condición debe ser i < array.length && array[i] != 0 y no al revés. Si no hubiera ningún 0 en el array, i llegaría a valer array.length y, con el orden invertido, Java intentaría leer array[array.length] antes de comprobar el límite: ArrayIndexOutOfBoundsException. Con &&, si la primera parte es falsa, la segunda ni se evalúa.

Invertir un array​

Para invertir un array intercambiamos el primer elemento con el último, el segundo con el penúltimo, y así hasta llegar a la mitad. Para intercambiar dos valores necesitamos una variable auxiliar:

int[] numeros = {1, 2, 3, 4, 5};

for (int i = 0; i < numeros.length / 2; i++) {
    int auxiliar = numeros[i];
    numeros[i] = numeros[numeros.length - 1 - i];
    numeros[numeros.length - 1 - i] = auxiliar;
}
// numeros ahora es {5, 4, 3, 2, 1}
consejo

¿Por qué solo hasta length / 2? Porque cada vuelta intercambia dos posiciones. Si recorriéramos el array entero, deshacerías el intercambio al llegar a la segunda mitad y el array quedaría como al principio.
