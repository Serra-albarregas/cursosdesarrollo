6. Respuestas y códigos de estado

Cada respuesta HTTP comienza con un número de tres cifras que resume qué ha pasado. Es la primera información que leen el cliente, los proxies, los monitores y tú mismo depurando a las dos de la madrugada. Devolver el código correcto es parte del contrato de tu API.

6.1. Las cinco familias​

FamiliaNombreSignificado
1xxInformativaPetición recibida, proceso en curso
2xxÉxitoLa petición se recibió, entendió y aceptó
3xxRedirecciónHace falta una acción adicional
4xxError del clienteLa petición es incorrecta
5xxError del servidorLa petición era válida, pero el servidor falló
información

4xx = "la has liado tú (cliente)"; 5xx = "la he liado yo (servidor)". Devolver un 500 ante datos mal formados del usuario es un error de diseño muy común y hace que tus alertas de producción sean ruido inútil.

6.2. Los códigos más importantes​

2xx — Éxito​

CódigoNombreCuándo
200OKÉxito general con cuerpo de respuesta
201CreatedRecurso creado. Acompañar de Location
204No ContentÉxito sin cuerpo (típico de DELETE y PUT)
206Partial ContentRespuesta parcial (Range), descargas y vídeo

3xx — Redirección​

CódigoNombreCuándo
301Moved PermanentlyCambio definitivo de URL; el cliente actualiza marcadores
302FoundRedirección temporal (histórica, ambigua)
303See OtherTras un POST, redirige a un GET. Base del patrón POST/Redirect/GET
304Not ModifiedLa copia en caché sigue siendo válida
307Temporary RedirectComo 302 pero conserva el método
308Permanent RedirectComo 301 pero conserva el método

4xx — Error del cliente​

CódigoNombreCuándo
400Bad RequestSintaxis o validación incorrecta
401UnauthorizedNo autenticado (nombre desafortunado)
403ForbiddenAutenticado pero sin permiso
404Not FoundEl recurso no existe
405Method Not AllowedMétodo no admitido; devolver Allow
406Not AcceptableNo se puede satisfacer el Accept
409ConflictConflicto de estado (duplicado, versión obsoleta)
410GoneExistió y se eliminó definitivamente
415Unsupported Media TypeContent-Type no soportado
422Unprocessable ContentSintaxis válida, semántica incorrecta
429Too Many RequestsLímite de peticiones superado; devolver Retry-After

5xx — Error del servidor​

CódigoNombreCuándo
500Internal Server ErrorExcepción no controlada
501Not ImplementedMétodo no implementado
502Bad GatewayUn proxy recibió una respuesta inválida del upstream
503Service UnavailableSobrecarga o mantenimiento
504Gateway TimeoutEl upstream no respondió a tiempo
