6. Expresiones de Thymeleaf

En la página anterior vimos que una plantilla se rellena con los datos del modelo mediante atributos th:*. El valor de esos atributos es una expresión: una pequeña fórmula que Thymeleaf evalúa en el servidor y cuyo resultado se inserta en el HTML. En esta página vemos qué se puede escribir en ellas.

6.1. Atributos th:* y expresiones​

Para poder usar Thymeleaf, la etiqueta html de la plantilla declara el espacio de nombres th:

<html xmlns:th="http://www.thymeleaf.org">

Cada atributo th:* combina qué se modifica (el contenido, un atributo, la visibilidad...) con la expresión que calcula el valor:

<p th:text="${mensaje}">Texto de ejemplo</p>

Aquí th:text indica que se sustituye el contenido de la etiqueta, y ${mensaje} es la expresión que obtiene el valor. El texto original ("Texto de ejemplo") solo se muestra si abrimos el archivo sin pasar por Spring.

Existen cinco tipos de expresiones, que se distinguen por el símbolo inicial. En esta página vemos las de variable y las de selección; el resto se resumen en el último apartado.

6.2. Expresiones de variable: ${...}​

Son las más habituales. Acceden a los datos que el controlador dejó en el modelo, usando como nombre la clave de addAttribute.

Usaremos la clase Alumno de la página anterior (con id, nombre, curso y edad, y sus getters) y un controlador que la envía:

@GetMapping("/{id}/ficha")
public String ficha(@PathVariable int id, Model model) {
    model.addAttribute("alumno", new Alumno(id, "Lucía Márquez", "2DAW", 19));
    model.addAttribute("nota", 7.5);
    return "alumno-ficha";
}

Acceso a propiedades y métodos​

<p th:text="${alumno.nombre}">Nombre</p>
<p th:text="${alumno.getCurso()}">Curso</p>
<p th:text="${alumno.nombre.length()}">Longitud</p>
  • ${alumno.nombre} es la forma habitual: Thymeleaf llama internamente a getNombre().
  • También se pueden invocar métodos directamente (getCurso(), length()...).

Listas y mapas​

<p th:text="${alumnos[0].nombre}">Primer alumno</p>
<p th:text="${mapa['clave']}">Valor del mapa</p>

Valores nulos​

Si el atributo no existe en el modelo o vale null, th:text no produce error: simplemente deja la etiqueta vacía. Lo que sí produce error es acceder a una propiedad de un objeto que es null (por ejemplo, ${alumno.nombre} cuando alumno es null). Para evitarlo se usa el operador de navegación segura ?.:

<p th:text="${alumno?.nombre}">Nombre</p>

Si alumno es null, la expresión devuelve null en lugar de fallar.

6.3. th:text frente a th:utext​

Los dos atributos insertan un valor como contenido de la etiqueta, pero tratan el HTML de forma distinta:

th:textth:utext
Escapa el HTMLSíNo
Qué ocurre con <b>Hola</b>Se muestra el texto literal <b>Hola</b>El navegador lo interpreta y muestra Hola en negrita
SeguridadSegura por defectoPeligrosa con datos del usuario
<p th:text="${contenido}">...</p>     <!-- muestra las etiquetas como texto -->
<p th:utext="${contenido}">...</p>    <!-- interpreta las etiquetas como HTML -->
nota

Usa th:text siempre que puedas Si el valor procede del usuario (un comentario, un nombre escrito en un formulario...) y se inserta con th:utext, alguien podría introducir código HTML o JavaScript malicioso que se ejecutaría en el navegador de otros usuarios (ataque XSS). th:utext solo debe usarse con contenido que controlamos nosotros.

6.4. Literales y concatenación​

Dentro de una expresión se pueden escribir valores fijos (literales):

TipoEjemplos
Texto'Hola' (entre comillas simples)
Número42, 3.14
Booleanotrue, false
Nulonull

Para unir textos se usa el operador +:

<p th:text="'Curso: ' + ${alumno.curso}">Curso</p>

Sustitución de literales​

Cuando hay que mezclar mucho texto fijo con variables, la concatenación se vuelve incómoda. La sustitución de literales encierra todo entre barras verticales |...| y permite escribir las variables directamente dentro del texto:

<p th:text="|Curso: ${alumno.curso}, edad: ${alumno.edad}|">Datos</p>

Es equivalente a 'Curso: ' + ${alumno.curso} + ', edad: ' + ${alumno.edad}, pero mucho más legible.

nota

Alternativa: inlining Dentro del texto de una etiqueta también se pueden insertar variables con doble corchete, sin necesidad de th:text: <p>Hola, [[${alumno.nombre}]]</p>. Es cómodo en frases cortas, aunque en esta unidad usaremos preferentemente th:text.

6.5. Operadores​

Dentro de las expresiones se pueden usar operadores similares a los de Java:

TipoOperadores
Aritméticos+, -, *, /, %
Comparación>, <, >=, <= (o gt, lt, ge, le)
Igualdad==, != (o eq, ne)
Lógicosand, or, ! (o not)
Condicional (ternario)condición ? valorSi : valorNo
Elvisvalor ?: valorPorDefecto
<p th:text="${alumno.edad + 1}">Edad el año que viene</p>
<p th:text="${alumno.edad >= 18 and alumno.curso == '2DAW'}">Condición</p>
nota

Alias de los operadores de comparación Los alias gt, lt, ge, le existen porque los símbolos < y > pueden confundirse con las etiquetas HTML. Es especialmente recomendable usar lt en lugar de < dentro de los atributos.

Operador ternario​

Elige entre dos valores según una condición:

<p th:text="${alumno.edad >= 18} ? 'Mayor de edad' : 'Menor de edad'">Estado</p>

Operador Elvis​

Devuelve el valor si no es null, y un valor por defecto en caso contrario:

<p th:text="${alumno.curso} ?: 'Sin curso asignado'">Curso</p>

El Elvis solo actúa cuando el valor es null: un texto vacío ("") no es null, por lo que se mostraría vacío.

6.6. Expresiones de selección: *{...} y th:object​

Cuando hay que mostrar varias propiedades del mismo objeto, repetir ${alumno. en cada línea es tedioso. Con th:object se selecciona un objeto, y dentro de esa etiqueta las expresiones *{...} se refieren directamente a sus propiedades:

<div th:object="${alumno}">
    <p th:text="*{nombre}">Nombre</p>
    <p th:text="*{curso}">Curso</p>
    <p th:text="*{edad}">Edad</p>
</div>

Es equivalente a escribir ${alumno.nombre}, ${alumno.curso} y ${alumno.edad}.

  • ${...} sigue disponible dentro del bloque para acceder al resto de variables del modelo, y se pueden mezclar ambas.
  • th:object afecta a la etiqueta donde se declara y a todas las que contiene.
nota

Más adelante Con los formularios, th:object se usará también para enlazar un formulario con un objeto. Aquí lo usamos solo para mostrar datos.

6.7. Objetos de utilidad y th:with​

Objetos de utilidad​

Thymeleaf incluye una serie de objetos con métodos auxiliares, que se distinguen por empezar con #. Se usan dentro de ${...}:

ObjetoPara qué sirve
#stringsTrabajar con textos
#numbersFormatear números
#listsTrabajar con listas
#temporalsFormatear fechas modernas (LocalDate, LocalDateTime)

A continuación, los métodos más habituales de cada uno.

#strings​

MétodoQué haceEjemplo
isEmpty(str)true si el texto es null o vacío${#strings.isEmpty(alumno.curso)}
length(str)Longitud del texto${#strings.length(alumno.nombre)}
toUpperCase(str) / toLowerCase(str)Cambia a mayúsculas/minúsculas${#strings.toUpperCase(alumno.nombre)}
contains(str, sub)true si str contiene sub${#strings.contains(alumno.nombre, 'María')}
substring(str, inicio, fin)Extrae una parte del texto${#strings.substring(alumno.nombre, 0, 3)}
trim(str)Elimina espacios al principio y al final${#strings.trim(texto)}
concat(str1, str2, ...)Concatena varios textos${#strings.concat(alumno.nombre, ' - ', alumno.curso)}

#numbers​

MétodoQué haceEjemplo
formatDecimal(num, digitosEnteros, decimales)Formatea con dígitos enteros y decimales fijos${#numbers.formatDecimal(nota, 1, 2)} → 7.50
formatInteger(num, digitos)Formatea como entero, rellenando con ceros si hace falta${#numbers.formatInteger(id, 3)} → 007
formatCurrency(num)Formatea como moneda, según la configuración regional${#numbers.formatCurrency(precio)}
formatPercent(num, digitosEnteros, decimales)Formatea como porcentaje${#numbers.formatPercent(ratio, 1, 0)}

#lists​

MétodoQué haceEjemplo
isEmpty(lista)true si la lista es null o vacía${#lists.isEmpty(alumnos)}
size(lista)Número de elementos${#lists.size(alumnos)}
contains(lista, elemento)true si la lista contiene ese elemento${#lists.contains(cursos, '2DAW')}
sort(lista)Devuelve la lista ordenada${#lists.sort(nombres)}

#temporals​

MétodoQué haceEjemplo
format(fecha, patron)Formatea la fecha con el patrón indicado${#temporals.format(alumno.fechaAlta, 'dd/MM/yyyy')}
day(fecha) / month(fecha) / year(fecha)Extraen la parte correspondiente${#temporals.year(alumno.fechaAlta)}
formatISO(fecha)Formatea en formato estándar ISO-8601${#temporals.formatISO(alumno.fechaAlta)}
nota

#temporals frente a #dates #temporals trabaja con las clases modernas de fecha de Java (java.time, como LocalDate), que son las que usaremos en esta unidad. Si en algún momento trabajas con la clase antigua java.util.Date, existe el objeto equivalente #dates, con métodos muy similares.

<p th:text="${#strings.toUpperCase(alumno.nombre)}">NOMBRE</p>
<p th:text="${#numbers.formatDecimal(nota, 1, 2)}">7.50</p>
<p th:text="${#lists.size(alumnos)}">0</p>

formatDecimal(numero, digitosEnteros, decimales) muestra el número con el número mínimo de dígitos enteros y los decimales indicados.

Variables locales con th:with​

Si un valor calculado se necesita varias veces, se puede guardar en una variable local con th:with. Solo existe dentro de la etiqueta donde se declara y las que contiene:

<div th:with="mayor=${alumno.edad >= 18}">
    <p th:text="${mayor} ? 'Puede matricularse solo' : 'Necesita autorización'">Estado</p>
    <p th:text="|¿Mayor de edad? ${mayor}|">Resultado</p>
</div>

6.8. Ejemplo completo​

Controlador (visto en el apartado 6.2):

@GetMapping("/{id}/ficha")
public String ficha(@PathVariable int id, Model model) {
    model.addAttribute("alumno", new Alumno(id, "Lucía Márquez", "2DAW", 19));
    model.addAttribute("nota", 7.5);
    return "alumno-ficha";
}

Plantilla alumno-ficha.html:

<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<head>
    <meta charset="UTF-8">
    <title>Ficha</title>
</head>
<body>
    <h1 th:text="|Ficha de ${#strings.toUpperCase(alumno.nombre)}|">Ficha</h1>

    <div th:object="${alumno}">
        <p th:text="'Curso: ' + *{curso}">Curso</p>
        <p th:text="*{edad >= 18} ? 'Mayor de edad' : 'Menor de edad'">Edad</p>
    </div>

    <p th:text="|Nota media: ${#numbers.formatDecimal(nota, 1, 2)}|">Nota</p>
</body>
</html>

Al visitar GET /alumnos/7/ficha, el HTML generado es:

<h1>Ficha de LUCÍA MÁRQUEZ</h1>

<div>
    <p>Curso: 2DAW</p>
    <p>Mayor de edad</p>
</div>

<p>Nota media: 7.50</p>

6.9. Resumen de los tipos de expresión​

SintaxisNombreEjemploPara qué sirve
${...}Variable${alumno.nombre}Acceder a los datos del modelo
*{...}Selección*{nombre} (con th:object)Acceder a las propiedades del objeto seleccionado
@{...}Enlace@{/alumnos/{id}(id=${alumno.id})}Construir URLs
~{...}Fragmento~{layout :: cabecera}Reutilizar trozos de plantilla
#{...}Mensaje#{alumno.bienvenida}Textos externos (internacionalización)

Los tres últimos se muestran aquí solo para que reconozcas el símbolo si te los encuentras; se explican con detalle, y con ejemplos completos, en las páginas indicadas.
