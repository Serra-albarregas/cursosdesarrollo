En esta página aprenderás a utilizar la etiqueta `<img>`, imágenes adaptables, formatos de imagen, SVG, marcos, sombras y la etiqueta `<picture>`.

## Etiqueta `<img>`

La etiqueta `<img>` se usa para incrustar imágenes en una página web. A continuación, se muestra un ejemplo básico:

El atributo `alt` es importante por razones de accesibilidad; describe el contenido de la imagen si esta no se carga o para lectores de pantalla.

<HtmlPlayground initialHtml={`<img src="${paisajeUrl}" alt="Descripción de la imagen" width="300" />`} />

## Propiedades `width` y `height`

Usar los atributos `width` y `height` permite especificar el tamaño de la imagen en píxeles. Sin embargo, es mejor evitar distorsionar las imágenes (cambiar solo uno de estos atributos sin mantener la proporción). Ejemplo:

<HtmlPlayground initialHtml={`<img src="${paisajeUrl}" width="400" height="300" alt="Imagen con ancho y alto definidos" />`} />

:::tip
Aunque el tamaño final se suela ajustar con CSS, es buena práctica incluir siempre `width` y `height` (con la proporción real de la imagen) en el propio `<img>`. Así el navegador reserva el espacio antes de que la imagen cargue y evita que el resto de la página "salte" mientras se descarga.
:::

## Propiedades `width` y `height` en CSS

También se pueden fijar `width` y `height` con CSS en lugar de con atributos HTML. A diferencia de los atributos, si los valores no mantienen la proporción original, la imagen se deforma igualmente.

<HtmlCssPlayground
  initialHtml={`<img src="${paisajeUrl}" alt="Imagen con ancho y alto definidos" />`}
  initialCss={`img {
  height: 300px;
  width: 200px;
}`}
/>

## Imágenes adaptables

Para que las imágenes se adapten al tamaño del contenedor, podemos usar CSS. Esto asegura que la imagen se redimensione correctamente en dispositivos móviles. Para ello se configura el tamaño porcentualmente y, para mantener la proporción, el valor `auto`:

<HtmlCssPlayground
  initialHtml={`<img src="${paisajeUrl}" alt="Imagen adaptable" />`}
  initialCss={`img {
  width: 60%;
  height: auto;
}`}
/>

En este caso, la imagen se adapta al tamaño de su contenedor manteniendo las proporciones correctas.

## Imágenes adaptables con tamaño máximo

El problema de `width: 60%` es que, si el contenedor es muy grande, la imagen puede llegar a mostrarse más grande que su tamaño real y se ve borrosa. Usando `max-width` en lugar de `width`, la imagen se sigue adaptando a contenedores pequeños, pero nunca crece más allá de su tamaño original.

<HtmlCssPlayground
  initialHtml={`<img src="${paisajePngUrl}" alt="Imagen adaptable" />`}
  initialCss={`img {
  max-width: 100%;
  height: auto;
}`}
/>

## Formatos de imagen

Los formatos de imagen más comunes en la web son JPEG, PNG, GIF y WebP. Aquí una descripción de cada uno:

- **JPEG:** adecuado para fotos con muchos colores y detalles. Alta compresión, pero con pérdida de calidad.
- **PNG:** ideal para imágenes con áreas transparentes y gráficos. Sin pérdida de calidad.
- **GIF:** formato limitado a 256 colores, ideal para animaciones sencillas.
- **WebP:** formato moderno que ofrece compresión sin pérdida o con pérdida, y soporta transparencia.

## Imágenes SVG

SVG (Gráficos Vectoriales Escalables) es un formato basado en vectores, lo que significa que puede escalarse sin pérdida de calidad. Es ideal para logotipos, íconos y gráficos simples:

![Imagen raster](img/gato_chico.png)
![Imagen vectorial](img/gato.svg)

Las imágenes SVG son independientes de la resolución, por lo que son perfectas para pantallas de alta densidad de píxeles.

## Marco y sombra en imágenes

Con CSS, es fácil añadir marcos y sombras a las imágenes para mejorar su presentación. Ejemplo de CSS para añadir un marco y sombra:

<HtmlCssPlayground
  initialHtml={`<img src="${paisajeUrl}" alt="Imagen con marco y sombra" />`}
  initialCss={`img {
  width: 60%;
  height: auto;
  border: 5px solid #2980b9;
  border-radius: 10px;
  /* desplazamiento-x, desplazamiento-y, desenfoque, extensión, color */
  box-shadow: 4px 4px 10px 2px rgba(0, 0, 0, 0.5);
}`}
/>

## La etiqueta `<picture>`

La etiqueta `<picture>` permite especificar diferentes fuentes de imagen para adaptarse a diferentes condiciones, como el tamaño de la pantalla o la densidad de píxeles. Contiene varios elementos `<source>` con un atributo `media` (una media query) y un atributo `srcset` con la imagen a usar si esa media query se cumple. El navegador evalúa los `<source>` en orden y usa el primero que coincide; si ninguno coincide, usa el `<img>` final, que además sirve como alternativa para navegadores que no soportan `<picture>`.

<HtmlPlayground initialHtml={`<picture>
      <source srcset="${gatoGrandeUrl}" media="(min-width: 801px)">
      <source srcset="${gatoMenosGrandeUrl}" media="(min-width: 600px) and (max-width: 800px)">
      <source srcset="${gatoChicoUrl}" media="(max-width: 599px)">
      <img src="${gatoChicoUrl}" alt="Descripción de la imagen">
</picture>`} />

En este ejemplo, se cargarán diferentes versiones de la imagen según el tamaño de la pantalla del usuario.

## Ejemplo con `picture` y orientación "portrait"

El siguiente ejemplo utiliza la etiqueta `<picture>` para cargar diferentes imágenes dependiendo de la orientación de la pantalla (`portrait` o `landscape`).

<HtmlPlayground initialHtml={`<picture>
      <source media="(orientation: portrait)" srcset="${portraitUrl}" />
      <source media="(orientation: landscape)" srcset="${landscapeUrl}" />
      <img src="${landscapeUrl}" alt="Ejemplo de picture con orientación portrait" />
</picture>`} layout="stacked"/>
