Las tablas se utilizan para organizar información con un formato de filas y columnas.

:::warning
Las tablas sirven para mostrar **datos tabulares**. No deben usarse para maquetar la página (colocar menús, columnas de texto, etc.); para eso existen CSS, `flexbox` y `grid`.
:::

## Crear una tabla

Para crear una tabla básica en HTML, se utiliza la etiqueta `<table>`, que define el contenedor de la tabla. Dentro de esta etiqueta, se utilizan filas definidas por la etiqueta `<tr>` (table row) y celdas dentro de esas filas, las cuales son creadas por las etiquetas `<td>` (table data). Cada fila puede contener múltiples celdas.

- `<table>`: define la tabla.
- `<tr>`: define una fila de la tabla.
- `<td>`: define una celda dentro de una fila.
- `border="1"`: atributo de `<table>` que dibuja los bordes. Está obsoleto en HTML5, pero se sigue admitiendo con el valor `1` y sirve para ver la estructura de la tabla. La forma actual de dar bordes es CSS (se explica más abajo).

        <td>Fila 1 Col 3</td>

    </tr>
    <tr>
        <td>Fila 2 Col 1</td>

</table>`} />

## Celdas de cabecera

Las celdas de cabecera dentro de una tabla se definen con la etiqueta `<th>` (table header), que representa la cabecera de una columna o de una fila. Estas celdas tienen un estilo predeterminado de texto en negrita y alineado al centro, aunque pueden ser estilizadas mediante CSS.

El atributo `scope` indica a qué se refiere la cabecera y ayuda a los lectores de pantalla a leer bien la tabla.

- `<th>`: define una celda de cabecera.
- `scope="col"`: la cabecera se refiere a toda la columna.
- `scope="row"`: la cabecera se refiere a toda la fila.

<HtmlPlayground initialHtml={`<table border="1">
    <tr>
        <th scope="col">Cabecera 1</th>
        <th scope="col">Cabecera 2</th>
        <th scope="col">Cabecera 3</th>
        <th scope="col">Cabecera 4</th>
    </tr>
    <tr>
        <td>Fila 2 Col 1</td>
        <td>Fila 2 Col 2</td>
        <td>Fila 2 Col 3</td>
        <td>Fila 2 Col 4</td>
    </tr>
    <tr>
        <td>Fila 3 Col 1</td>
        <td>Fila 3 Col 2</td>
        <td>Fila 3 Col 3</td>
        <td>Fila 3 Col 4</td>
    </tr>
</table>`} />

## Combinar celdas

Para combinar varias celdas dentro de una tabla, se pueden utilizar los atributos `colspan` y `rowspan`. El atributo `colspan` permite que una celda ocupe varias columnas, mientras que `rowspan` hace que una celda ocupe varias filas.

- `colspan`: define cuántas columnas abarcará una celda.
- `rowspan`: define cuántas filas abarcará una celda.

:::warning
Al combinar celdas, **hay que eliminar las celdas que quedan cubiertas**. Cada fila debe seguir sumando el mismo número de columnas. En el ejemplo, la primera fila tiene una celda de 2 columnas y dos celdas normales (4 columnas en total). La fila 4 solo tiene una celda porque las demás están ocupadas por las combinaciones de la fila 3.
:::

<HtmlPlayground initialHtml={`<table border="1">
    <tr>
        <td colspan="2">Fila 1 Col 1 y 2</td>
        <td>Fila 1 Col 3</td>
        <td>Fila 1 Col 4</td>
    </tr>
    <tr>
        <td>Fila 2 Col 1</td>
        <td>Fila 2 Col 2</td>
        <td>Fila 2 Col 3</td>
        <td>Fila 2 Col 4</td>
    </tr>
    <tr>
        <td colspan="2" rowspan="2">Fila 3 y 4 Col 1 y 2</td>
        <td>Fila 3 Col 3</td>
        <td rowspan="2">Fila 3 y 4 Col 4</td>
    </tr>
    <tr>
        <td>Fila 4 Col 3</td>
    </tr>
</table>`} />

## Título de la tabla

La etiqueta `<caption>` añade un título a la tabla. Debe ser el **primer elemento** dentro de `<table>` y, por defecto, se muestra encima de la tabla. Además de describir su contenido, ayuda a los lectores de pantalla.

- `<caption>`: define el título de la tabla.

<HtmlPlayground initialHtml={`<table border="1">
    <caption>Notas del primer trimestre</caption>
    <tr>
        <th scope="col">Módulo</th>
        <th scope="col">Nota</th>
    </tr>
    <tr>
        <td>Lenguajes de Marcas</td>
        <td>8</td>
    </tr>
    <tr>
        <td>Programación</td>
        <td>7</td>
    </tr>
</table>`} />

## Cabecera, cuerpo y pie

Una tabla puede dividirse en tres secciones: cabecera (`<thead>`), cuerpo (`<tbody>`) y pie (`<tfoot>`). La cabecera contiene las celdas `<th>` que definen las columnas, el cuerpo contiene los datos y el pie puede incluir filas de totales o resumen. Esto mejora la semántica y la accesibilidad de la tabla, y permite darle estilo a cada sección por separado.

Conviene escribirlas en este orden: primero `<thead>`, después `<tbody>` y al final `<tfoot>`.

- `<thead>`: define la cabecera de la tabla.
- `<tbody>`: define el cuerpo de la tabla.
- `<tfoot>`: define el pie de la tabla.

<HtmlPlayground initialHtml={`<table border="1">

        <tr>
            <th scope="col">Producto</th>
            <th scope="col">Unidades</th>
            <th scope="col">Importe (€)</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Cuaderno</td>
            <td>10</td>
            <td>20</td>
        </tr>
        <tr>
            <td>Bolígrafo</td>

        <tr>
            <th scope="row">Total</th>

        </tr>
    </tfoot>
</table>`} />

## Tablas con bordes

Para agregar bordes a una tabla con CSS se utiliza la propiedad `border`, que permite especificar el grosor, el estilo y el color del borde en un solo valor (por ejemplo, `1px solid black`). Si se aplica solo al elemento `<table>`, únicamente se dibuja el **borde exterior** de la tabla; las celdas quedan sin borde.

- `border`: define el borde de un elemento (grosor, estilo y color).

## Celdas con bordes

Para que las celdas también tengan borde, se aplica la propiedad `border` a los elementos `<td>` (y a `<th>` si la tabla tiene cabeceras). Se pueden escribir todos los selectores juntos, separados por comas, para no repetir el estilo. Es importante notar que si no se colapsan los bordes, estos aparecerán duplicados entre las celdas.

## Tabla y celdas con bordes colapsados

Al colapsar los bordes de una tabla con CSS utilizando la propiedad `border-collapse: collapse;`, los bordes de las celdas adyacentes se combinan en uno solo. Esto evita que se dupliquen los bordes entre celdas.

- `border-collapse`: define cómo se manejan los bordes adyacentes en una tabla.

## Espacio interior y alineación de las celdas

Por defecto, el contenido de las celdas queda pegado a su borde y la tabla se ve apretada. La propiedad `padding` añade espacio entre el contenido y el borde de la celda, y `text-align` controla la alineación horizontal del texto.

- `padding`: define el espacio interior de la celda.
- `text-align`: define la alineación horizontal del texto (`left`, `center` o `right`).

<HtmlCssPlayground
  initialHtml={`<table>
    <tr>
        <th>Producto</th>
        <th>Unidades</th>
        <th>Importe (€)</th>
    </tr>
    <tr>
        <td>Cuaderno</td>
        <td>10</td>
        <td>20</td>
    </tr>
    <tr>
        <td>Bolígrafo</td>
        <td>25</td>
        <td>25</td>
    </tr>
</table>`}
  initialCss={`table, th, td {
    border: 1px solid black;
    border-collapse: collapse;
}

th, td {
    padding: 10px;
}

td {
    text-align: center;
}`}
/>

## Cambiar el tamaño de la tabla

Por defecto, el tamaño de una tabla se ajusta al contenido de sus celdas. Con CSS se puede fijar el tamaño de la tabla completa: `width` establece el ancho total (las columnas se reparten ese espacio) y `height` establece la altura total (las filas se reparten esa altura). Los valores pueden ser fijos (`500px`) o relativos (`50%`).

- `width`: define el ancho de la tabla.
- `height`: define la altura de la tabla.

  initialHtml={`<table>

        <td>Fila 1 Col 4</td>
    </tr>

        <td>Fila 2 Col 1</td>
        <td>Fila 2 Col 2</td>
        <td>Fila 2 Col 3</td>
        <td>Fila 2 Col 4</td>

  initialCss={`table, td {

## Cambiar el tamaño de las celdas

Para ajustar el tamaño de las celdas se pueden usar las propiedades CSS `width` y `height` sobre los elementos `<td>` o mediante clases CSS. Hay que tener en cuenta que las celdas de una misma columna comparten el ancho, y las de una misma fila comparten la altura. Por eso, cambiar el ancho de una celda afecta a toda su columna, y cambiar su altura afecta a toda su fila.

- `td { width }`: define el ancho de una celda (y de toda su columna).
- `td { height }`: define la altura de una celda (y de toda su fila).

## Ajustar el tamaño a la pantalla

Para hacer que la tabla se ajuste a la pantalla de forma automática, se pueden utilizar unidades relativas como porcentajes en la propiedad `width` de la tabla y de las celdas. Esto asegura que la tabla se escale según el tamaño de la ventana del navegador, proporcionando una experiencia más adaptable en pantallas de diferentes tamaños.

Hay que tener cuidado con los tamaños mínimos: si `min-width` es mayor que el ancho de la pantalla (por ejemplo, en un móvil), la tabla se saldrá de la pantalla y aparecerá scroll horizontal.

- `width: 100%`: hace que la tabla ocupe todo el ancho disponible.
- `max-width`: configura un tamaño máximo para la tabla.
- `min-width`: configura un tamaño mínimo para la tabla.
- `margin: auto`: centra la tabla.
- `td { width: 25% }`: especifica que cada celda debe ocupar el 25% de la tabla.

## Selectores para filas pares e impares

Con CSS es posible alternar los estilos de las filas pares e impares de una tabla usando selectores como `:nth-child(even)` para las filas pares y `:nth-child(odd)` para las impares. Esto mejora la legibilidad de los datos al ofrecer un contraste visual entre las filas.

Conviene aplicar estos selectores solo a las filas del cuerpo (`tbody tr`). Si se escriben como `tr:nth-child(...)`, también afectan a la fila de cabecera y esta no se distingue del resto.

- `tbody tr:nth-child(even)`: aplica estilos a las filas pares del cuerpo.
- `tbody tr:nth-child(odd)`: aplica estilos a las filas impares del cuerpo.

## Estilo de columnas completas

Con `<colgroup>` y `<col>` se puede dar estilo a una columna entera sin tener que modificar cada celda. `<colgroup>` va justo debajo de `<table>` (o de `<caption>`, si existe) y antes de las filas; dentro, cada `<col>` representa una columna. Con el atributo `span` un mismo `<col>` puede representar varias columnas seguidas.

Solo funcionan algunas propiedades sobre las columnas: `background`, `border`, `width` y `visibility`.

- `<colgroup>`: agrupa las definiciones de columnas.
- `<col>`: representa una columna de la tabla.
- `span`: número de columnas a las que afecta un `<col>`.

<HtmlCssPlayground
